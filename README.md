# v2RayTun-Connect

**Windows-клиент для управления VPN и прокси-подключениями**

Готовая структура проекта с отдельным установщиком для Windows.

</div>

---

## 🚀 Установка

Для установки последней версии:

1. Откройте раздел **Releases**.
2. Скачайте файл **`v2RayTun_Setup.exe`** из нужного релиза.
3. Откройте **`v2RayTun_Setup.exe`** и следуйте инструкциям установщика.
4. После завершения установки запустите приложение.

> Для установки используйте установщик из официального GitHub Release проекта.

## 📂 Структура

```text
v2RayTun-Connect/
├── config/
│   ├── default.json
│   └── profiles.json
├── data/
│   └── README.txt
├── logs/
│   └── .gitkeep
├── scripts/
│   ├── start.bat
│   └── stop.bat
├── .gitignore
├── LICENSE
└── README.md
```

Установщик **`v2RayTun_Setup.exe`** публикуется отдельно в разделе **Releases**.

---

## ⚙️ Конфигурация

Файлы конфигурации находятся в каталоге `config`.

Основной профиль:

```text
config/default.json
```

Дополнительные профили:

```text
config/profiles.json
```

---

## 🛠 Диагностика

При возникновении проблем:

- проверьте выбранную конфигурацию;
- перезапустите приложение;
- проверьте содержимое каталога `logs`;
- убедитесь, что установщик и необходимые компоненты не блокируются Windows.

---

## 📋 Требования

- Windows 10 / Windows 11
- Права, необходимые установщику для установки приложения
- Корректная конфигурация подключения

---

## ⚠️ Важно

Используйте только собственные или разрешённые конфигурации подключения.

Не запускайте установщики и конфигурационные файлы из непроверенных источников.
